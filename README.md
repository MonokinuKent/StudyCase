# Profile Card - Git & GitHub Workshop

## Deskripsi Proyek
Proyek ini merupakan implementasi pembuatan tampilan **website** Profile Card interaktif. Pengembangan proyek ini difokuskan pada penerapan alur kerja kolaborasi ketat menggunakan Git dan GitHub. Setiap anggota ditugaskan untuk bekerja pada **branch** terpisah dan menggabungkan kodenya melalui proses **Pull Request** serta **Code Review**.
